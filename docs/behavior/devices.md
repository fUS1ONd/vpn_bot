# Управление устройствами

Как пользователь смотрит и сбрасывает свои HWID-устройства.

## Вход в раздел

Пользователь заходит в управление устройствами inline-кнопкой «📱 Мои устройства»
прямо из карточки «👤 Моя подписка». Отдельного reply-подменю подписки больше нет —
уровень навигации схлопнут.

## Что можно сделать

- посмотреть подключённые HWID-устройства;
- отвязать одно устройство;
- сбросить все устройства.

Кнопка устройства подписана `🗑 <платформа> · <модель>`: тап по ней сразу снимает
HWID-привязку, без экрана подтверждения. Подтверждение здесь намеренно не
показывается — действие обратимое, устройство переподключается по той же ссылке
подписки, а лишний экран стоил бы дороже ошибочного тапа. Иконка `🗑` совпадает с
соседней «🗑 Сбросить все устройства», чтобы обе кнопки читались одинаково.

## Навигация: экран редактирует карточку

Экран устройств **редактирует** сообщение карточки, а не шлёт новое. Поэтому
кнопка «🔙 Назад» (callback `cbSubCard`) возвращает карточку на место, а не
удаляет сообщение.

## Код и API

- Реализация — `internal/bot/devices.go`.
- API Remnawave — `GetUserHwidDevices` / `DeleteUserHwidDevice` / `DeleteAllUserHwidDevices`.

## Смежное

Сброс всех устройств выполняется также первым шагом при перевыпуске ссылки
подписки — см. `docs/specs/2026-08-05-subscription-page-flow-design.md`.
