# Багрепорт

Как пользователь сообщает о проблеме и что получает админ.

## Flow

Зарегистрированный пользователь нажимает кнопку «🛠 Сообщить о проблеме» в главном
меню, затем:

1. **Выбирает один или несколько серверов.** Мультивыбор сделан inline-тогглами с
   галочками ✅ плюс кнопка «Готово». В списке только включённые хосты
   (`isDisabled=false`), в том числе скрытые. Если хостов нет — шаг выбора сервера
   пропускается.
2. **Выбирает категорию проблемы.**
3. **Опционально пишет комментарий.**

## Что уходит админу

Бот шлёт структурированный репорт админу в личку: TG ID, имя, статус подписки,
список серверов, категория, текст.

## Хранение состояния

Без таблиц БД: сессия и кулдаун (10 минут на пользователя) хранятся in-memory.
