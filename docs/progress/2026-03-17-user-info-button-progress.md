# Прогресс: кнопка "Информация" для пользователей

## Что сделано

### 1. Добавлена новая кнопка в пользовательские меню

В `internal/bot/keyboards.go` добавлена кнопка `Информация`.

Она отображается:

- у обычных пользователей в `UserMenuKeyboard()`;
- у модераторов в `UserMenuKeyboardModerator()`;
- у админа в режиме пользователя через общий `b.userKeyboard(...)`.

### 2. Добавлено информационное сообщение и роутинг

В `internal/bot/messages.go` добавлено новое HTML-сообщение `MsgInfo`:

- заголовок `💡 Помощь и контакты`;
- контакт `@fus1ond`;
- ссылка на политику конфиденциальности;
- ссылка на пользовательское соглашение.

В `internal/bot/handlers.go`:

- добавлена ветка `case BtnInfo` в `handleTextMessage`;
- добавлен обработчик `handleInfo`, который отправляет `MsgInfo`;
- сохранён возврат в текущее пользовательское меню через `b.userKeyboard(...)`.

### 3. Расширено тестовое покрытие

Добавлены тесты на:

- наличие кнопки `Информация` в обычном пользовательском меню;
- наличие кнопки `Информация` в меню модератора;
- выдачу корректного `MsgInfo`;
- роутинг кнопки через `handleTextMessage`;
- интеграционную проверку `b.userKeyboard(...)` для модератора.

### 4. Обновлена документация

В `README.md` добавлено описание новой пользовательской кнопки `Информация`.
