# Прогресс: тестовая оплата для администратора

**План:** [2026-07-16-admin-test-payment-price.md](../plans/2026-07-16-admin-test-payment-price.md)

## Статус

Реализация завершена.

- Добавлен `ADMIN_TEST_PAYMENT_PRICE`: положительное значение включает для `ADMIN_ID` кнопку оплаты с отдельной тестовой суммой; `0`, отрицательное и некорректное значение её выключают.
- Создаваемый платёж помечается `is_test`. Он проходит через создание и callback провайдера, но не меняет подписку, не участвует в earnings и финансовой статистике, а chargeback только фиксируется и отправляет алерт без бана или удаления администратора.
- Конфигурация, видимость кнопки, реальная сумма запроса к провайдеру, метка платежа, confirmation и chargeback покрыты тестами.
- После успешного callback (включая webhook ЮKassa) в чат администратора отправляется только сообщение «✅ Платёжная система работает.».

## Проверка

Выполнены `make fmt` и `make tests` с Go-кешами в `/tmp`; оба завершились успешно.
