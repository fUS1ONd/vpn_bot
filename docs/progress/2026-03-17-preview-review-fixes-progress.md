## Что исправлено

### 1. Возвращена жёсткая блокировка забаненных пользователей

В `internal/bot/handlers.go` добавлена ранняя проверка бана в текстовом роутере:

- забаненный пользователь больше не может попасть в preview-ветки через прямую отправку текста кнопок;
- при попытке нажать `👤 Мой статус`, `🌐 Подключить` или `🎟 Активировать код` возвращается сообщение о блокировке;
- `isPreviewGuest` больше не считает забаненного пользователя гостем preview-режима.

### 2. Добрано тестовое покрытие preview-инструкций

В `internal/bot/handlers_test.go` добавлены регрессионные тесты на:

- блокировку banned-пользователя в preview;
- роутинг `BtnInstructions` в меню инструкций;
- подстановку `PreviewSubscriptionPlaceholder` для iOS;
- подстановку `PreviewSubscriptionPlaceholder` для Android.

Desktop-путь, добавленный ранее, сохранён и теперь покрытие соответствует требованиям плана.
