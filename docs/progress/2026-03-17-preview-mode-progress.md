## Что сделано

### 1. Добавлен runtime preview-режим

В `internal/bot` добавлен in-memory флаг preview-режима:

- по умолчанию режим выключен при старте бота;
- админ может переключать его из главного меню;
- состояние живёт только до перезапуска процесса и не сохраняется в БД или `.env`.

### 2. Реализован гостевой UX для незарегистрированных пользователей

Когда preview включён и пользователя нет в БД:

- `/start` открывает гостевое меню вместо немедленного запроса инвайта;
- появляется кнопка `🎟 Активировать код`;
- `👤 Мой статус` и `🌐 Подключить` возвращают демо-ответы;
- инструкции показывают плейсхолдер вместо реальной subscription URL;
- deep link `/start <code>` продолжает активировать инвайт по обычному сценарию.

При этом до ввода валидного инвайта не создаются ни запись в `users`, ни пользователь в Remnawave.

### 3. Обновлены тесты и документация

- Добавлены тесты на guest keyboard, preview `/start`, демо-ответы и admin toggle.
- Обновлён `README.md` с описанием preview-режима и его ограничений.
