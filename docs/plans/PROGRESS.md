## Миграция завершена! 🎉

### Что реализовано

**Бот:**
- Система инвайтов для регистрации новых пользователей
- Интеграция с Remnawave API (создание пользователей, получение статуса, управление трафиком)
- Кнопки пользователя: Мой статус, Подключить, Поддержать, Инструкции
- Админ-панель: Создание инвайтов, Добавление трафика, Бан пользователей, Рассылка
- Scheduler для сброса увеличенных лимитов 1-го числа месяца
- Рассылка только активным пользователям (status=ACTIVE в Remnawave)

**Мигратор:**
- CLI-утилита `cmd/migrator`
- Миграция только активных пользователей из старой БД
- Режимы `--dry-run` и `--live`
- Логирование в файл

### Использование мигратора

```bash
# Сборка
go build -o migrator ./cmd/migrator

# Показать что будет мигрировано (без изменений)
./migrator --dry-run --old-db /path/to/users.db

# Выполнить миграцию
./migrator --live --old-db /path/to/users.db
```
