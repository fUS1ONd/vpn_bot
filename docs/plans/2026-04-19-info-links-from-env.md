# План: вынести ссылки и контакт из `MsgInfo` в .env

**Дата:** 2026-04-19
**Ветка:** `feat/info-links-from-env`

## Контекст

В кнопке «Информация» (хэндлер `handleInfo`) показываются две ссылки на
telegra.ph — политика конфиденциальности и пользовательское соглашение.
Обе страницы на telegra.ph протухли (удалены/недоступны), а URL
захардкожены в константе `MsgInfo` в `internal/bot/messages.go:54-59`.
Любая правка требует релиза бота.

Задача — сделать ссылки и контакт поддержки редактируемыми через
переменные окружения, чтобы их можно было менять без пересборки
(достаточно правки `.env` и рестарта). Новые рабочие URL пользователь
подставит сам на проде; в коде остаются плейсхолдеры в `.env.example`.

## Решение

Перевести `MsgInfo` из константы в функцию-форматтер `BuildInfoMessage(cfg)`,
которая подставляет значения трёх новых переменных окружения в HTML-шаблон.
Переменные обязательны при старте — без них `config.Load()` возвращает
ошибку, как уже делает для `BOT_TOKEN`, `REMNAWAVE_URL`, `REMNAWAVE_API_TOKEN`.

### Новые переменные окружения

| Переменная | Назначение |
|---|---|
| `PRIVACY_POLICY_URL` | URL страницы политики конфиденциальности (telegra.ph или любой другой) |
| `TERMS_OF_SERVICE_URL` | URL страницы пользовательского соглашения |
| `SUPPORT_CONTACT` | Контакт поддержки в произвольной форме — `@username`, `t.me/...`, email и т. п. Вставляется как есть в HTML; админ отвечает за безопасность значения. |

Все три — обязательные, без дефолтов. Мотивация: старые дефолты уже
протухли и снова заложить плейсхолдер в код — значит повторить ту же
ошибку в будущем.

### Файлы и изменения

**`internal/config/config.go`**
- Добавить 3 поля в `Config`: `PrivacyPolicyURL`, `TermsOfServiceURL`, `SupportContact` (все `string`).
- В `Load()` читать через `os.Getenv` и проверять непустоту — возвращать
  ошибку аналогично существующим обязательным полям.

**`internal/bot/messages.go`**
- Удалить константу `MsgInfo`.
- Добавить функцию `BuildInfoMessage(cfg *config.Config) string`, которая
  возвращает HTML с подстановкой трёх значений. Формат сообщения
  сохранить один-в-один.
- URL экранировать через `html.EscapeString`; контакт не экранировать
  (может содержать HTML-разметку на усмотрение админа, как и `DonateText`).

**`internal/bot/handlers.go:691-696`**
- Заменить `c.Send(MsgInfo, ...)` на `c.Send(BuildInfoMessage(b.config), ...)`.

**`internal/bot/messages_test.go:56-62`**
- Переписать `TestMsgInfoContainsExpectedLinks` на тест функции
  `BuildInfoMessage(cfg)`.

**`internal/config/config_test.go`**
- Добавить кейсы: `Load()` возвращает ошибку при отсутствии каждой из
  трёх новых переменных.

**`internal/bot/handlers_test.go:612, 627, 681`**
- Заменить сравнения `MsgInfo` на `BuildInfoMessage(bot.config)`.

**`.env.example`**
- Добавить блок с новыми переменными и подробными комментариями.
  Плейсхолдеры без реальных URL.

**`CLAUDE.md`**
- В секцию «Переменные окружения» добавить три новых.

**`docs/progress/2026-04-19-info-links-env-progress.md`**
- Создаётся в конце работы. Содержит ревью плана.
