# VPN-бот

Telegram-бот, продающий доступ к VPN. Приём денег через платёжных провайдеров,
выдача и продление доступа — через панель Remnawave, налоговый учёт — через
кабинет самозанятого «Мой налог».

## Language

### Доступ и пользователи

**Подписка**:
Право пользователя на доступ к VPN до определённой даты. Живёт в Remnawave, бот
её только двигает.
_Avoid_: аккаунт, тариф

**Триал**:
Короткая подписка, выдаваемая по referral-приглашению, с лимитом трафика.
_Avoid_: пробный период, демо

**Grace-период**:
Время между истечением подписки и отключением доступа, когда пользователь ещё не
отключён, но уже не считается активным.
_Avoid_: льготный период, отсрочка

**Автокик**:
Отключение доступа по истечении grace-периода. Не является баном — пользователь
может вернуться по новому приглашению.
_Avoid_: бан, блокировка

**Связка**:
Соответствие между Telegram ID пользователя и пользователем панели, хранимое в
таблице `users`. Панель 2.8.x адресует пользователя UUID, панель 3.x — числовым
`id`, поэтому связка хранит оба идентификатора (`remnawave_uuid`, `remnawave_id`);
у созданных на 3.x UUID нет вовсе.
_Avoid_: маппинг, привязка, линк

**Ссылка на пользователя панели** (`UserRef`):
То, что бот передаёт в каждый вызов панели по конкретному пользователю. Собирается
только из связки, единственным хелпером; какой из двух идентификаторов уйдёт в
запрос, решает клиент по версии панели.
_Avoid_: uuid, идентификатор пользователя

**Приглашение**:
Код, дающий право зарегистрироваться в боте. Служебное (админское) — бессрочное и
бесплатное; referral — созданное пользователем, живёт 30 суток и даёт триал.
_Avoid_: инвайт, промокод

### Деньги

**Платёж**:
Локальная запись о попытке оплаты: сумма, провайдер, статус, момент
подтверждения. Принадлежит боту и неизменна после подтверждения.
_Avoid_: транзакция, покупка, заказ

**Провайдер**:
Платёжная система, через которую проходят деньги: Platega или YooKassa.
_Avoid_: агрегатор, шлюз, эквайер

**Подтверждение платежа**:
Момент, когда провайдер сообщил, что деньги получены. Фиксируется в
`confirmed_at` в UTC и служит датой расчёта для налоговой.
_Avoid_: оплата, успех, capture

**Тестовый платёж**:
Платёж, созданный админом для проверки боевого магазина. Деньги настоящие,
поэтому для налоговой он ничем не отличается от обычного, хотя из внутренней
статистики исключается.
_Avoid_: пробный платёж, фейковый платёж

### Налоговый учёт

**Чек**:
Запись о доходе, зарегистрированная в «Мой налог» по одному платежу. Связь с
платежом строго 1:1.
_Avoid_: квитанция, receipt, income

**Доход**:
Термин ФНС для того, что в кабинете соответствует чеку. Употребляется только при
описании их API (`GET /incomes`), в остальном коде — «чек».
_Avoid_: выручка, поступление

**Метка**:
Случайная строка, которую бот дописывает к наименованию услуги перед отправкой
чека и сохраняет у себя. Позволяет найти свой чек в кабинете, когда ответ ФНС
потерялся, — uuid чека придумывает ФНС, а метку придумываем мы.
_Avoid_: идентификатор, ключ идемпотентности, тег

**Сверка**:
Поиск в кабинете ФНС чека по метке, когда бот не знает, создался тот чек или нет.
_Avoid_: реконсиляция, синхронизация

**Аннулирование**:
Отмена уже зарегистрированного чека. Возможна только целиком, частичного
аннулирования у ФНС нет.
_Avoid_: отмена, сторно, возврат

### Эксплуатация

**Режим обслуживания**:
Состояние бота, в котором скрыта оплата и не выполняются отключения, но
остальная функциональность работает.
_Avoid_: maintenance, техработы

**Нода**:
Сервер с VPN, зарегистрированный в Remnawave и опрашиваемый мониторингом.
_Avoid_: сервер, хост, инстанс
