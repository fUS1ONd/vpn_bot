# VPN Bot (Remnawave)

Telegram-бот управления VPN на базе [Remnawave](https://remnawave.com).
Пользователи регистрируются по инвайт-кодам, управляют подключениями и отслеживают трафик.
Поддерживает роли: пользователь, модератор, администратор.

## Быстрый старт

```bash
git clone https://github.com/<user>/vpn_bot.git
cd vpn_bot
cp .env.example .env
# Заполни .env своими ключами
make up
```

Логи:

```bash
make logs
```

| `VICTORIA_METRICS_URL`         | —            | URL VictoriaMetrics (дефолт: `http://victoriametrics:8428`) |

## Функциональность

### Пользователь

| Кнопка          | Действие                                                             |
| --------------- | -------------------------------------------------------------------- |
| `/start`        | Регистрация по инвайт-коду или вход для зарегистрированных           |
| `/start <code>` | Автоматическая активация кода из ссылки-приглашения                  |
| `👤 Мой статус` | Статус подписки (активен / истёк / заблокирован) и трафик за месяц   |
| `🌐 Подключить` | Ссылка подписки для копирования в VPN-клиент                         |
| `📡 Серверы`    | Live-дашборд мониторинга нод (обновляется каждые 5 сек)              |
| `📚 Инструкции` | Инструкции по настройке клиентов: iOS, Android, Windows/Linux, macOS |
| `💸 Поддержать` | Показывает реквизиты из `DONATE_TEXT`                                |

### Модератор

Назначается администратором. В главном меню появляется дополнительная кнопка `🎟 Приглашения`:

| Кнопка                   | Действие                                           |
| ------------------------ | -------------------------------------------------- |
| `📨 Создать приглашение` | Генерирует инвайт-код и ссылку для отправки        |
| `📋 Мои приглашения`     | Список своих кодов (статус, кто активировал, дата) |
| `🗑 Удалить приглашение` | Удаление своего неиспользованного кода             |

### Администратор

Кнопка `📋 Управление` открывает панель:

| Кнопка                  | Действие                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `🎟 Создать инвайт`     | Генерирует инвайт-код и ссылку для отправки                                        |
| `📋 Коды`               | Список всех кодов: статус, кто активировал, дата, кто создал (модератор или админ) |
| `🗑 Удалить код`        | Удаление неиспользованного кода (использованные защищены)                          |
| `🚫 Забанить`           | Удаление пользователя из БД бота и Remnawave                                       |
| `📢 Рассылка`           | Отправка сообщения всем активным пользователям (текст, фото, видео, документы)     |
| `👥 Модераторы`         | Управление ролями: назначить / список / снять модератора                           |
| `👤 Режим пользователя` | Просмотр бота глазами пользователя                                                 |

При активации нового инвайта админ получает уведомление с Telegram ID, username и именем.

## Поведение в граничных случаях

**Инвайт от модератора vs от администратора** — функционально одинаковые. Разница только в отображении: в списке кодов (`📋 Коды`) видно кто создал код.

**Срок подписки** — подписка бессрочная. Счётчик использованного трафика сбрасывается автоматически 1-го числа каждого месяца (стратегия `MONTH` в Remnawave). Статус (`ACTIVE` / `EXPIRED` / `DISABLED`) управляется самим Remnawave.

**Истёкший статус** — кнопка `👤 Мой статус` покажет что подписка истекла. Бот сам ничего не предпринимает — нет ни уведомлений об истечении, ни автоматического кика.

**Бан пользователя** — каскадная операция:

1. Пользователь удаляется из Remnawave → теряет доступ ко всем серверам
2. Пользователь удаляется из БД бота
3. Если пользователь был модератором — все его неиспользованные инвайты удаляются

После бана повторная регистрация через новый инвайт технически возможна — бот не блокирует Telegram ID.

**Снятие модератора** — все неиспользованные инвайты модератора удаляются автоматически. Сам пользователь остаётся зарегистрированным.

**Рассылка** — отправляется только пользователям со статусом `ACTIVE` в Remnawave. Пользователи с истёкшей подпиской или заблокированные не получают.

## Мониторинг нод

Бот мониторит VPS-ноды через Prometheus Node Exporter и отображает их состояние в live-дашборде (кнопка `📡 Серверы`). При уходе ноды в офлайн или перегрузке приходит алерт в Telegram.

### Настройка

На каждой ноде выполни:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/fUS1ONd/vpn_bot/main/scripts/install-node-exporter.sh) <IP_СЕРВЕРА_С_БОТОМ>
```

Скрипт устанавливает Node Exporter, открывает порт 9100 только для IP сервера с ботом и добавляет сервис в автозапуск.

В Remnawave добавь тег `bw:<Mbps>` к ноде для указания bandwidth (например `bw:1000` = 1 Gbit). По умолчанию 1000 Mbps.

### Алерты

- Нода **OFFLINE** — Node Exporter не отвечает
- **Load Index > 80%** — нода перегружена (`Load Average × 100 / bandwidth`)

## Разработка

```bash
go mod download     # Установить зависимости
make down           # Остановить бота

make logs           # Показать логи
```
